# Australian Household Finance & Wealth Analysis

## Overview
A Business Intelligence project exploring Australian household finance and wealth using ABS data from the March 2026 release.

## Objectives
- Explore household balance-sheet and wealth measures.
- Examine income, consumption, saving and net-worth indicators over time.
- Prepare structured datasets for Power BI analysis.

## Data Sources
Australian Bureau of Statistics (ABS), *Australian National Accounts: Finance and Wealth, March 2026*.
- Table 35: Household Balance Sheet.
- Table 36: Analytical Measures of Household Income, Consumption, Saving and Wealth.

## Tools & Technologies
- Power BI Desktop
- Power Query
- DAX, where applicable
- Microsoft Excel

## My Contribution

- Standardised date and numerical data types.
- Investigated missing values, potential outliers and duplicate measures.
- Developed a data dictionary and prepared the datasets for time-based analysis.
